## 📌 Visão Geral

![Painel Executivo e Demonstração Interativa](assets/images/projects/portifolio.png)

Este portfólio foi desenhado com foco comercial e posicionamento estratégico para **pessoas e microempresas**. O objetivo é transformar números e dados complexos em **clareza financeira**, estancando vazamentos de dinheiro e automatizando rotinas operacionais sem burocracia.

Unindo a visão de processos da **Administração** à engenharia da **Ciência da Computação**, as soluções apresentadas substituem controles manuais e planilhas desorganizadas por **fluxos autônomos 24/7** e **painéis inteligentes**.

---

## 🚀 Funcionalidades & Arquitetura da Plataforma

### 1. 📊 Showcase Executivo & Simulação em Tempo Real
- **Dashboard estilo Streamlit**: Interface inspirada nos melhores painéis analíticos, apresentando faturamento, despesas e **lucro líquido positivo preservado** (+R$ 12.370).
- **Projeção com Machine Learning**: Gráfico vetorial SVG interativo demonstrando curvas históricas de receitas vs. despesas e projeção inteligente para os meses seguintes.
- **Detecção de Desvios (Outliers)**: Rastreamento automático de custos invisíveis (taxas de maquininha, picos de frete e desvios operacionais).
- **Simulador de Cenários**: Controle seletivo de projeções com recalculo dinâmico dos gráficos, barras de despesas e notificações operacionais.

### 2. 📱 Mockup Smartphone Executivo Sincronizado
- Demonstração de experiência mobile integrada com barra de status iOS/Android, cartão de saldo real estimado, atalhos rápidos da operação e disparo de rotinas automáticas no WhatsApp.

### 3. 🤖 Estrutura de Soluções Sob Medida (3 Pilares)
- **Agentes Autônomos & Automação de Rotinas**: Robôs em nuvem para atendimento, cobrança, conciliação e triagem trabalhando 24/7 de forma independente.
- **Previsão & Controle da Empresa por ML**: Modelos preditivos para identificar onde o dinheiro está escorrendo antes do fechamento do mês.
- **Automação de Conteúdo & Comunicação**: Esteira automatizada de newsletters, roteiros estruturados para gravação, e-mails com design atrativo e scripts aceleradores de fluxo.

### 4. 🔍 Ficha Técnica & Visualização Expandida de Projetos
- Modal interativo com visão de arquitetura de software, métricas de resultado, stack técnica e botão direto de solicitação de orçamento via WhatsApp.

### 5. 💬 Canal de Conversão Direto no WhatsApp
- Integração de atendimento sem atritos direcionando para o número profissional `(21) 99967-7281`.

## 🛠 Tecnologias & Engenharia Utilizadas

- **HTML5 Semântico**: Estrutura acessível com metatags OpenGraph completas para pré-visualização em redes sociais e mensageiros.
- **CSS3 Moderno**:
  - Paleta personalizada no tema Midnight Luxury (`#010D26`, dourado `#F2AA52`, esmeralda `#10b981`);
  - Layout com **CSS Grid** e **CSS Subgrid** para alinhamento horizontal rigoroso entre cards de serviços;
  - Glassmorphism com `backdrop-filter`, sombras em camadas e efeitos dinâmicos de luz (*spotlight effect*);
  - Design totalmente responsivo para desktop, tablets e celulares.
- **JavaScript ES6 (Vanilla)**:
  - Motor de simulação preditiva com recálculo de curvas SVG em tempo real;
  - Interação fluida de filtros, modais acessíveis e menu mobile;
  - ScrollReveal para transições suaves de scroll.

## 💻 Como Rodar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/vitugrey/portifolio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd portifolio
   ```

3. Abra o arquivo `index.html` diretamente em seu navegador favorito ou inicie um servidor estático local:
   ```bash
   # Com Python:
   python -m http.server 8000

   # Com Node/npx:
   npx serve .
   ```

4. Acesse no navegador em `http://localhost:8000`.
