## 🚀 Funcionalidades & Arquitetura da Plataforma

### 1. 📊 Showcase Executivo & Simulação em Tempo Real
- **Painel de Controle Dark Industrial**: Interface de dados de alta precisão com 4 cards de métricas nivelados (*Faturamento Mensal*, *Despesas Operacionais*, *Lucro Líquido Real* e *Previsão/Margem*).
- **Controle Preditivo de Machine Learning**: Slider dinâmico de 1 a 6 meses de previsão que recalcula instantaneamente os ganhos acumulados e estende a curva no gráfico SVG interativo.
- **Detecção de Anomalias (Outliers)**: Rastreamento inteligente de custos invisíveis (taxas atípicas de cartão, picos de frete e despesas fora do padrão).
- **Simulador de Cenários**: Alternância em tempo real entre *Visão Geral*, *Cortar Desperdícios (-15%)* e *Expansão de Vendas (+25%)*.

### 2. 📱 Smartphone Executivo Sincronizado
- Mockup realista de celular integrado na seção de demonstração, exibindo saldo em conta sincronizado com a previsão do painel desktop e botão com feedback de envio de relatórios para WhatsApp.

### 3. 🎯 Onde Posso Te Ajudar (Soluções Sob Medida)
- **🤖 Agentes Autônomos**: Crie seu próprio agente autônomo para automatizar tarefas e rotinas diárias da sua empresa, com atendimento automático inteligente 24/7 e triagem qualificada antes de passar para um humano.
- **📈 Dashboard com IA**: Um painel inteligente que traduz seus números e já sabe para onde seu dinheiro está indo, permitindo fechar o mês com total clareza, previsões preditivas e estratégias baseadas no histórico.
- **✨ Automação de Conteúdo**: Esteira completa para criar newsletters semanais personalizadas, roteiros de vídeos estruturados com base nas suas referências e e-mails comerciais com design moderno e elegante.

### 4. 💼 Soluções Desenvolvidas (Projetos em Destaque)
- **Agente Virtual Inteligente & Triagem**: Sistema de atendimento ao cliente 24/7 com IA contextual, filtro de leads e notificações imediatas.
- **[Finance Engine](https://github.com/vitugrey/Finance-Engine) (Plataforma Executiva)**: Sistema proprietário desenvolvido pela GreyWorks para consolidação patrimonial e engenharia de caixa. Conecta custódia da B3, cotações em tempo real via API do Yahoo Finance (`yfinance`), diagnóstico automático de *Runway* (autonomia em meses) e simulador estocástico de metas de independência financeira.
  - **Carrossel com 4 Telas Reais**: Visão Geral & KPIs, Portfólio & Alocação B3, Fluxo de Caixa e Metas com Juros Compostos.
  - **Modal de Vendas**: Comparativo direto de *O Problema de Antes* vs. *A Solução com o Projeto*.
  - **Ações Estratégicas 70/30**: Botão principal verde `Quero uma solução similar` (ocupando $7/10$) e botão `Demo` (ocupando $3/10$).
- **Automação de Rotinas & Relatórios**: Robôs em nuvem para coleta de dados de fornecedores, geração e envio de ordens de serviço e conciliação bancária automática.

## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/vitugrey/portifolio.git
   ```

2. Entre no diretório do projeto:
   ```bash
   cd portifolio
   ```

3. Inicie um servidor HTTP local:
   ```bash
   # Com Python:
   python -m http.server 8000
   ```

4. Acesse no navegador em `http://localhost:8000`.
